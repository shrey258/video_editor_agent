# INDEX

A map of every file you can edit, what it owns, and where to look first. Generated, vendored and runtime directories are listed at the bottom so you skip them.

## Root

| File | Owns |
| --- | --- |
| `CLAUDE.md` | Agent rules: commands, architecture, gotchas. Read it first. `AGENTS.md` is a symlink to it. |
| `DESIGN.md` | UI rules: tokens, components, when to use what. Read it before touching any `.tsx`. |
| `README.md` | Human-facing pitch and setup. |
| `mprocs.yaml` | `mprocs` runs the backend on :8000 and the frontend on :3000 together. |
| `.github/workflows/ci.yml` | CI runs backend `pytest -q`, then frontend `lint`, `test` and `build`. |
| `.codex/environments/environment.toml` | Codex "Run" action. It is autogenerated, so don't edit it. |
| `graphify-out/` | Knowledge graph (`GRAPH_REPORT.md`, `graph.json`, `graph.html`). Query it before grepping. |

## Backend: `backend/` (FastAPI + FFmpeg + Gemini)

| File | Owns |
| --- | --- |
| `app/main.py` | Every HTTP route, CORS, env config, and the range merge/speed-segment math. The only entry point. |
| `app/video_tools.py` | Every `ffmpeg`/`ffprobe` subprocess call: probe, trim, cut-and-stitch, speed (`atempo` chain), sprite sheets. |
| `app/gemini_agent.py` | Gemini REST calls: `parse_intent` (prompt → edit op) and `suggest_cuts_from_sprites`. Each has a regex/heuristic fallback when there's no key. |
| `app/schemas.py` | Pydantic request/response models. The contract with the frontend. |
| `app/validators.py` | `parse_time_like` (for `"1:05"`, `"65s"` and similar) and `validate_trim`. |
| `app/services/media_service.py` | Upload saving, sprite-param validation, probe-or-delete. |
| `app/services/token_service.py` | Estimates Gemini tokens for raw video vs sprite sheets. |
| `tests/test_api.py` | Only backend test file. `TestClient` against `app.main.app`. |
| `.env.example` | `GEMINI_API_KEY`, `MEDIA_ROOT`, `MAX_FILE_SIZE_MB`, `MAX_VIDEO_DURATION_SEC`, `SPRITE_PERSIST`, `CORS_ORIGINS`, `VERCEL_FRONTEND_URL`. |
| `Dockerfile`, `fly.toml` | Deploy to Fly.io (`video-editor-agent-backend`, Python 3.11 with ffmpeg). |

### Routes (`app/main.py`)

| Route | Does |
| --- | --- |
| `GET /health` | Liveness. |
| `POST /upload` | Saves a video to `media/uploads` and returns its id and duration. |
| `POST /edit-request` | Natural-language prompt → `parse_intent` → ffmpeg edit → output URL. |
| `POST /analyze/sprites` | Video → sprite sheets for scrubbing and AI context. |
| `POST /analyze/token-estimate[-from-file]` | Token cost comparison. |
| `POST /ai/suggest-cuts-from-sprites` | Sprites + goal + chat history → suggested trim/speed ranges. |
| `POST /export/from-file` | Applies trim and speed ranges to an uploaded file and returns an mp4. |

## Data flow

```
file picked → store.loadFile (object URL, local preview)
  → inspector: POST /api/analyze/sprites → sprite sheets
  → inspector: POST /api/ai/suggest-cuts-from-sprites → setTrimRanges / setSpeedRanges
  → timeline edits the same ranges by hand
  → inspector: POST /api/export/from-file (file + ranges) → download mp4
```

## Skip these (generated, vendored, runtime)

`frontend/node_modules`, `frontend/.next`, `frontend/tsconfig.tsbuildinfo`, `backend/.venv`, `backend/.pytest_cache`, `.pycache`, `media/uploads|outputs|sprites` (user videos), `.env` / `.env.local` (secrets: never read them into output).
